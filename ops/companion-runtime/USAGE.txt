Mutable data: ~/.local/state/overlaykit-companion-local/companion
Private config/credentials: ~/.config/overlaykit-companion-local/
Immutable release: ~/.local/share/overlaykit-companion-local/releases/<sha256>
Runtime-only opaque TLS socket: /run/user/<uid>/overlaykit-companion-local/https.sock
No network ports are published by Docker; only explicit host loopback forwards.

without disabling TLS checks, patching Companion, or installing a host-wide CA.

Startup requires the unique approved MK2 serial present and no existing HID owner.

If boot/start occurred without the device, connect it then restart/reset-failed
the service. Reconnection while the app remains running uses the existing bounded
one-rescan-per-USB-epoch service. No OS reboot guarantee or new retry policy is made.

Status: systemctl --user status overlaykit-companion-local
Restart: systemctl --user restart overlaykit-companion-local
Stop: systemctl --user disable --now overlaykit-companion-local
Stopping preserves all profile/server data and credentials. Roll back only after
the owned production container is stopped; never run two HID owners. No automatic
profile reset, data migration, OBS operation, Git publication or acceptance occurs.
